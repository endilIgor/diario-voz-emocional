# Estratégia de Cobrança — Diário por Voz Emocional

## Recomendação principal

Usar modelo freemium com plano anual forte.

## Plano Grátis

Preço: R$ 0

Inclui:

- 3 check-ins por mês.
- Transcrição básica.
- Análise emocional simples.
- Histórico dos últimos 7 dias.
- Notificação diária simples.

Objetivo:

- Fazer o usuário experimentar o ritual.
- Criar sensação de valor.
- Incentivar upgrade quando o limite acabar.

## Plano Premium

Preço recomendado inicial: **R$ 14,90/mês**

Inclui:

- Check-ins ilimitados.
- Histórico completo.
- Resumos automáticos.
- Tendências semanais.
- Temas recorrentes.
- Perguntas reflexivas.
- Backup em nuvem.
- Exportação do diário.

## Plano Anual

Preço recomendado: **R$ 99,90/ano**

Posicionamento:

> Menos de R$ 0,28 por dia para manter um ritual de autoconsciência.

## Versão mais premium

Se o design ficar muito bom e usar IA real:

- Mensal: **R$ 19,90/mês**
- Anual: **R$ 149,90/ano**

Essa versão deve vender:

- IA para reflexões personalizadas.
- Relatórios emocionais semanais.
- Histórico ilimitado.
- Insights mais profundos.

## Paywall sugerido

Momento ideal para mostrar paywall:

1. Depois do terceiro check-in gratuito.
2. Quando usuário tenta abrir tendências semanais.
3. Quando usuário tenta acessar histórico antigo.
4. Após entregar um resultado bom, com CTA suave.

Texto de paywall:

```text
Continue seu ritual diário

Você fez 3 check-ins este mês. No Premium, você pode gravar todos os dias e acompanhar seus padrões emocionais ao longo do tempo.

[Começar Premium]
R$ 14,90/mês

[Economizar com anual]
R$ 99,90/ano
```

## O que colocar no Premium

Premium precisa liberar valor, não bloquear o primeiro momento mágico.

Deixar grátis:

- Primeiro check-in.
- Resultado básico.
- Algumas entradas.

Cobrar por:

- Frequência.
- Histórico.
- Tendências.
- Exportação.
- Insights mais ricos.

## Cuidado com custos

Se usar API de transcrição/IA:

- Limitar duração do áudio no plano grátis: 1 minuto.
- Limitar duração no Premium: 3 a 5 minutos.
- Salvar transcrição e resultado para não recalcular.
- Evitar gerar relatório semanal com IA toda hora; gerar 1 vez por semana.

## Frase de venda

> Um espaço privado para falar, entender e acompanhar seus dias — em menos de 1 minuto.

## Melhor preço para começar

Minha escolha para lançamento no Brasil:

- Grátis: 3 check-ins/mês.
- Premium mensal: R$ 14,90.
- Premium anual: R$ 99,90.

Depois de validar retenção, testar R$ 19,90/mês.
